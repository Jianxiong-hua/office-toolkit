# 小蓝盒 / Sky-Box 发展规划

> 纯前端办公工具站 · 零服务器 · 本地处理 · 隐私优先

## 项目定位

小蓝盒 (Sky-Box Office Toolkit) 是一个面向个人办公场景的纯前端 Web 工具集合。所有文件处理均在浏览器本地完成，无需上传服务器，适合处理敏感文档和普通办公文件。

**核心原则**：
- 先做出来，自己和周围的人能用起来；
- 不依赖服务器，降低部署和维护成本；
- 优先做高频、易实现、用户感知价值高的工具；
- 每个阶段都有明确的验收指标。

---

## 阶段划分总览

| 阶段 | 名称 | 周期 | 核心目标 | 主要功能 |
|------|------|------|----------|----------|
| Phase 1 | MVP | 4–6 周 | 自己和周围人能用起来 | PDF 合并/拆分/水印、图片压缩/转换/缩放/快速裁剪/扩展填充 |
| Phase 2 | 体验打磨 | 3–4 周 | 提升完成率和回访率 | 历史记录、PWA、深色模式、PDF 旋转/提取、图片批量重命名 |
| Phase 3 | 矩阵扩展 | 4–6 周 | 覆盖长尾流量，验证变现 | PDF 压缩、AI 抠图、图片转 PDF、HEIC 转换、轻度付费 |
| Phase 4 | 后端扩展 | 视数据而定 | 突破前端能力边界 | PDF↔Office 转换、OCR、视频处理、用户系统、API |

---

## Phase 1：MVP（4–6 周）

### 目标
- 完成 8 个基础工具；
- 建立统一的文件上传、处理、下载体验；
- 部署到 Vercel，自己和 5–10 位朋友能无报错完成一次完整流程。

### 功能范围

#### PDF 工具
1. **PDF 合并**：多文件合并、拖拽排序、下载；
2. **PDF 拆分**：按页码范围/每 N 页/单页提取拆分；
3. **PDF 水印**：文字水印、图片水印、位置、透明度、旋转。

#### 图片工具
4. **图片压缩**：质量调节、尺寸限制、格式选择、批量 ZIP；
5. **图片格式转换**：JPG ↔ PNG ↔ WebP ↔ BMP，单/批量；
6. **图片缩放/Downsize**：按宽度/高度/百分比缩放，锁定比例；
7. **图片快速裁剪**：5 种固定比例、旋转、翻转、原始图像信息展示；
8. **图片扩展填充（Padding）**：原图 1:1 放置，按 4 边像素或画布尺寸 + 中心偏移两种模式扩展画布。

### 配套基础设施
- 统一文件上传组件（拖拽 + 点击）；
- 统一文件列表组件（显示、删除、状态、下载）；
- 处理进度、取消按钮、错误提示；
- 每个工具页独立 SEO meta；
- sitemap.xml / robots.txt；
- 移动端适配；
- 基础 GA4 埋点；
- 反馈入口。

### 验收指标
- 自己和 5–10 个朋友能无报错完成一次完整流程；
- 所有工具在 Chrome / Edge / Safari 最新版正常运行；
- 首页到工具页点击率可观测；
- 无阻塞性 bug。

---

## Phase 2：体验打磨（3–4 周）

### 目标
- 让 Phase 1 的用户愿意再次使用；
- 通过 SEO 和口碑开始自然增长。

### 建议功能
| 功能 | 价值 |
|------|------|
| **PDF 页面旋转/提取** | 拆分、水印后的自然补充 |
| **图片批量重命名** | 提升批量处理场景效率 |
| **历史记录（IndexedDB）** | 保存最近处理记录，可重新下载 |
| **真正的拖拽排序** | 替代 PDF 合并中的上下按钮 |
| **键盘快捷键** | Esc 取消、Delete 删除、Ctrl+Enter 处理 |
| **PWA 支持** | 可添加到桌面，更像本地工具 |
| **深色模式** | 现代工具站标配 |
| **结果分享链接** | 不存储文件，只保存结果 metadata 的复现链接 |

### 验收指标
- 工具完成下载率 > 60%；
- 30 天内回访率 > 20%；
- 移动端访问量占比 > 30% 时体验无明显问题。

---

## Phase 3：矩阵扩展 + 轻度变现（4–6 周）

### 目标
- 覆盖更多长尾搜索词，获取自然流量；
- 验证用户付费意愿。

### 建议功能
| 功能 | 说明 |
|------|------|
| **PDF 压缩** | 纯前端压缩效果有限，但用户感知价值高 |
| **AI 抠图** | 使用 `@imgly/background-removal`，注意模型加载体验 |
| **图片背景替换/填充** | 抠图后的自然延伸 |
| **PDF 转图片 / 图片转 PDF** | 高频需求，纯前端可做 |
| **HEIC → JPG 转换** | 解决 iPhone 用户痛点 |
| **去广告 Pro 会员** | 去广告、批量上限提升、优先处理 |
| **多语言（英文版）** | 海外流量更大，竞争也更激烈 |

### 验收指标
- 自然搜索流量 > 500 UV/月；
- 付费转化率数据可观测（即使为 0 也要能追踪）；
- 新增工具使用率 > 15%。

---

## Phase 4：后端扩展（视数据而定）

### 触发条件
- 日活 > 1000；
- 用户明确反馈需要前端无法实现的功能；
- 月收入能覆盖基础服务器成本。

### 建议功能
| 功能 | 为什么需要后端 |
|------|---------------|
| **PDF ↔ Word/Excel/PPT 互转** | 需要 LibreOffice / Aspose 等后端服务 |
| **OCR 文字识别** | 需要 Tesseract 或云端 OCR API |
| **视频转 GIF / 压缩** | `ffmpeg.wasm` 只能处理小文件 |
| **云存储/跨设备同步** | 用户账号和历史记录同步 |
| **API 接口（企业版）** | 面向开发者或企业客户 |
| **团队协作空间** | 多人共享处理模板和结果 |

### 验收指标
- 后端功能使用率 > 10%；
- 月收入覆盖服务器 + 域名成本；
- 出现明确的 B 端需求或 API 调用量。

---

## 各阶段明确不做的事

| 阶段 | 不做的事 | 原因 |
|------|---------|------|
| Phase 1 | AI 抠图、视频处理、OCR、用户系统、多语言 | 超出 MVP 范围，前端能力或加载体验不足 |
| Phase 2 | 付费墙、后端服务 | 先验证留存，再验证变现 |
| Phase 3 | 复杂后端转换（PDF↔Office） | 需要服务器，成本和维护复杂度上升 |
| Phase 4 | 移动端原生 App | Web/PWA 已覆盖核心场景 |

---

## 长期愿景

成为中文互联网中一个**简单、可信、打开即用**的办公工具集合。长期可以通过：
- 广告收入覆盖基础成本；
- Pro 会员提供批量/高级功能；
- 企业 API 服务获取稳定收入。

但前提是先把 Phase 1 做出让人愿意推荐的产品。
