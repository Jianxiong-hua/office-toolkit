# Color Checker v3 — 设计文档

> 版本：v3（2026-08-16）
> 说明：本文档仅描述 v3 的最终形态，与 v1/v2（颜色库多角色 + 经验学习）完全不同。v3 是一次简化和重构。
> 关联项目：浩匣 / HaoXia Office Toolkit（纯前端 Next.js 工具站）

## 1. v3 定位与目标

对比度校验工具 v3 对前两版做**大幅简化与重构**：

| 维度 | v1/v2 | v3 |
|------|-------|----|
| 经验学习引擎 | ✅ 有（人工核验、色系安全线） | ❌ 删除 |
| 颜色角色（文字/背景） | ✅ 有（asText/asBg） | ❌ 删除 |
| 链接公式 | RGB 四则运算 | **HSV 比例运算** |
| 色卡生成 | 勾选文字色自动批量 | **手动添加校验对** |
| 颜色排序 | ❌ | ✅ 原生拖拽 |

**核心价值变化**：v3 回归"纯净的对比度计算"，用户显式管理"文字色×背景色"配对，通过 HSV 比例公式快速派生颜色并校验对比度。

**非目标**：
- 不做经验学习/人工核验（已删除）
- 不做颜色角色自动分组
- 不兼容 v2 数据（storage key 改为 v3，开发阶段无真实用户）

## 2. 颜色库数据模型（v3）

```ts
interface LibraryColor {
  id: string;
  name: string;
  /** 实际生效 RGB（派生色由公式计算，手动色=baseRgb） */
  rgb: RgbTuple;              // [r,g,b]
  /** 手动基准 RGB（派生色在公式失效时回退） */
  baseRgb: RgbTuple;
  /** 链接到其他颜色（派生色） */
  linked: boolean;
  /** 链接目标颜色 id */
  linkTargetId: string | null;
  /** HSV 比例公式（v3 核心） */
  linkFormula: HsvFormula | null;
}

interface HsvFormula {
  h: string;   // 色相公式，如 "H+15"（H=源色H）
  s: string;   // 饱和度公式，如 "S*0.8"
  v: string;   // 明度公式，如 "V*1.2"
}

interface ColorLibrary {
  colors: LibraryColor[];   // 有序数组（支持拖拽排序）
}
```

## 3. HSV 比例公式引擎（核心）

### 3.1 变量与语法
- 表达式引用**源色（链接目标）**的 HSV 通道：`H` / `S` / `V`
- 支持运算符：`+ - * /`、括号、一元负号、数字
- 语法与 v2 的 `formula.ts` 相同（安全 tokenizer，不 eval），但**变量是 H/S/V 而非 R/G/B**

### 3.2 自动生成公式（调节后反推）
用户在面板中把当前派生色的 H/S/V 调到目标值，工具对比**源色 HSV** 与**目标 HSV**，自动生成：

```
H: 源H + (目标H - 源H)      → 形如 "H+15"（色相偏移）
S: 源S × (目标S / 源S)      → 形如 "S*0.8"（饱和度比例）
V: 源V × (目标V / 源V)      → 形如 "V*1.2"（明度比例）
```

**特殊值防护**：
- 若 `源S === 0`（灰），无法用比例，退化生成 `S`（取源值，等价常量）或 `目标S`（常量）
- 若 `源V === 0`（黑），退化生成 `V` 或 `目标V`（常量）
- 目标与源相同 → 生成恒等公式 `H` / `S` / `V`

### 3.3 求值
```
evalHsvChannel(expr, srcHsv): 0-360（H）/ 0-100（S/V）| null（非法）
```
- H 结果 mod 360 归一（如 370 → 10）
- S/V 结果 clamp 到 [0,100]
- 结果取整

### 3.4 联动与防错
- 源色变化 → 重新计算所有链接到它的派生色（链式支持，DFS 防循环，复用 v2 resolveLibrary 框架）
- 公式非法 / 链接目标缺失 / 循环引用 → 标记 error 状态，保留 baseRgb
- 求值结果越界自动 clamp，不会产生非法颜色

## 4. UI 设计

### 4.1 颜色库面板（左）
```
┌────────────────────────────┐
│ 颜色库  N 色       ⤢可调高度 │
│ [导入] [CSV] [JSON]   [+添加]│
│ ┌────────────────────────┐ │
│ │ (可拖拽排序的颜色行)      │ │
│ │ ┌─┐ 名称  #RRGGBB  [✎][🗑]│ │
│ │ └─┘ ●链接→源名  [拖拽手柄]│ │
│ │ 链接色展开区：            │ │
│ │  源色  █  HSV: h s v     │ │
│ │  当前  █  H[+15] S[*0.8] │ │
│ │        V[*1.2]  [自动]   │ │
│ └────────────────────────┘ │
└────────────────────────────┘
```

**每行颜色**：
- 色块 + 名称 + HEX + 编辑/删除按钮
- 链接色：显示"链接→源名"，并**展开**显示两行：
  - **源色行**：色块 + 该色 HSV 值
  - **当前色行**：色块 + H/S/V 三个调节控件（可拖滑块或输入），旁边显示自动生成的公式文本（如 `H+15`）
- 调整 H/S/V 后 → 实时更新当前色 rgb + 公式

**拖拽排序**：原生 HTML5 DnD，拖动行手柄调整顺序，`colors` 数组顺序即展示顺序

### 4.2 校验色卡区（右，初始为空）
```
┌────────────────────────────┐
│ [＋ 添加校验色彩对]           │
│                            │
│ （初始为空，提示引导）         │
│                            │
│ 校验对1：文字[选择▼] 背景[选择▼]│
│  ┌────────────┐            │
│  │  预览区域    │ 对比度 4.5:1│
│  │  文字样例    │ 评级 AAA   │
│  │  （CVD 可选）│  [删除]    │
│  └────────────┘            │
└────────────────────────────┘
```

**添加校验对**：点击按钮 → 弹窗选"文字色"（从颜色库下拉）+ "背景色"（从颜色库下拉）→ 确认后生成一张色卡

**每张色卡**：
- 预览区：背景色 + 文字色样例（含 CVD 滤镜，可选切换）
- **对比度值**（自动计算，WCAG）：`ratio.toFixed(2):1`
- **评级**（AA/AAA/仅大文本/不达标，normal/large 切换）
- 删除按钮

### 4.3 顶栏
- 工具名 + 统计（配对数量）
- 文字规格切换（正文 4.5 / 大文本 3.0）
- 样例切换（中文/英文/数字）
- CVD 切换（正常/红/绿/蓝弱）

## 6. 功能清单

1. 颜色库：增删改、HSV 比例公式链接、拖拽排序、CSV/JSON 导入导出、模板下载

3. 顶栏：文字规格、样例、CVD 切换

## 7. 验收标准
1. 颜色库 6 色初始化，支持增删改、拖拽排序
2. 链接色：面板显示源色 HSV + 当前 HSV，H/S/V 可调，自动生成比例公式，源变则联动，防错 clamp
3. 校验区初始为空，按钮添加校验对，选文字+背景，生成色卡显示对比度/评级
4. 无经验学习/颜色角色残留
5. `tsc --noEmit` 通过，dev 手动验证核心流程
