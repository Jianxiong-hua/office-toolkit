### 1. 图片编辑（tools/image/edit）标注功能修复与增强

背景：用户反馈「测量功能做的是什么玩意，自己不知道测试一下吗」——旧代码写完后从未实测，走查即发现多处断链。

测量功能根因：AnnotationCanvas handleDown 给 measure 工具借用 `type: "rect"` 草稿（crop 借用合理，measure 不合理），handleUp 原样 onCreate 从不转换 → 画布 measure 渲染分支（线+端点+距离标签）与 measureList 结果面板全是死代码路径。表现为「拖动和松手都是矩形、坐标距离无任何显示」。

修复与增强：
- 草稿按类型分三支构造（rect 带 fillColor/fillOpacity；line；measure），避免对象字面量多余属性 TS 报错
- Shift 方向锁定条件扩展到 measure；手柄拖动与选中高亮手柄扩展到 measure；选中面板类型标签补 measure →「测量线」
- useEffect([tool]) 清理 draft：修复「拖动中切工具再松手，上一工具草稿被误创建为标注」
- 导出循环补 measure 分支：线 + 端点圆点 + 中点上方标签（measureLabel 与 SVG 共用同一函数）；textAlign 用完还原 "start"，避免污染后续 text 分支
- 面板颜色/线宽/线型 patch 排除 measure（types.ts 设计为样式固定）

画框填充色（用户确认方案：独立填充色选择器）：
- RectAnnotation 加 fillColor + fillOpacity（默认 0.5，DEFAULT_FILL_OPACITY）；SVG 用 fill/fillOpacity，canvas 用 hexToRgba 先 fill 后 stroke（半透明填充不洗淡描边）
- 工具栏填充区（色板 + 透明度滑杆）仅在 rect 工具或选中 rect 时出现；选中时控件回显该框当前值
- 滑杆：onChange 实时 updateAnnotation 不进栈；pointerdown/keydown onDragStart 记快照；pointerup/keyup 用 JSON 比较决定 onDragEnd(changed)——一次拖动只一个撤销点
- 附带修复：矩形命中层 fill='none' → 'transparent'，有填充后点框内部也能选中

工具栏重设计（用户确认方案：紧凑单行图标组）：
- 工具按钮改纯图标方块（h-8 w-8 + title 悬浮提示）；组间竖向分隔线；布局：工具组｜描边色｜填充+透明度（条件）｜线宽｜线型｜字号（条件）

右栏标注图层列表（用户确认方案：仅线/框/文本，测量走原全宽面板）：
- shapeList = 非 measure；`[...shapeList].reverse()` 展示，列表顶部 = 画布最上层（annotations 数组顺序即 SVG 渲染顺序，后者盖前者）
- moveAnnotation 与相邻元素交换（相邻为测量线时同样越过），边界禁用，入撤销栈
- 条目：类型图标 + shapeLabel 描述 + 点击选中 + 上移/下移/删除

### 踩坑与经验

1. **对象字面量多余属性检查**：`setDraft({type: "line", ..., fillColor})` 报 TS 错——联合类型 Annotation 每个分支只接受自己的字段，rect 专属字段必须按类型分支构造。
2. **useCallback 引用后声明的 const**：commitFillOpacity 引用 selected（组件内 599 行声明）但定义在 399 行 → TS2448 used before declaration。依赖选中态的回调要放在 selected 声明之后。
3. **range 滑杆连续 onChange 直接 patchSelected 会逐像素入栈**，撤销栈爆炸；复用拖手柄的 onDragStart/onDragEnd + JSON 比较模式，一次拖动一个撤销点。
4. **execute_command 走 PowerShell，无 head/tail**：用 `git --no-pager diff ... | Select-Object -First N`；`$var` 在双引号 -Command 里会被外层剥掉，整段脚本用单引号包裹；PowerShell 里 curl 是别名，用 curl.exe。
5. **Invoke-WebRequest 遇 308**（Next 尾斜杠重定向）：用 `curl.exe -L` 跟随，或直接请求带 / 的 URL。
