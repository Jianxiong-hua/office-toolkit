### 踩坑记录（普适规则）

1. **dev server 运行中严禁跑 npm run build**：build 重写 .next，dev 引用的 chunk 全部 404，
   页面退化成无样式裸 HTML。build 之后必须重启 dev server（杀 3000 端口进程再起）。
2. **React StrictMode 下 setState 的 updater 会被双调用**：在 updater 里嵌套调用其他 setState
   （如 setPast 的 updater 里 setFuture）会执行两次，撤销栈被重复推入。嵌套副作用必须移出 updater，
   改为直接读闭包值 + 多个平级 setState。
3. **canvas 查看器的滚轮缩放，尺寸与滚动必须同步写 DOM**：
   - setDisplayScale 后用 rAF 调 scrollLeft/Top，rAF 可能跑在 React 提交新布局之前，
     产生一帧「旧尺寸 + 新滚动」的中间画面（闪烁）；
   - ResizeObserver 回调里不能重置当前缩放——放大使内容溢出容器、出现滚动条、clientWidth 变化
     时会把 zoom 拉回 fit，表现为「放大无效」。
   正确做法：wheel 事件内同步改 wrapper 尺寸 + scroll + setState；observer 只更新 fitScaleRef。
4. **adjustPixels 是原地修改**：预览渲染前必须复制 ImageData（new ImageData(new Uint8ClampedArray(src.data), w, h)），
   否则缓存的源像素被污染，调参无法回退。
5. **Uint8ClampedArray 的隐式舍入是「四舍六入五取偶」**（10.5 -> 10），像素算法必须显式 Math.round。
6. **SVG 与 canvas 的文本渲染一致性**：同一基线公式（baseline = y + 0.9*fontSize + i*1.4*fontSize）
   + 同一换行来源（手动回车，textarea 软换行无法传递给渲染层）。行高倍数常量化共用。
7. **工具故障绕行**（2026-10-11 实测）：write_to_file / replace_in_file 对长内容间歇性报
   「missing required argument filePath」；execute_command 的命令内容里不能出现反斜杠+n 字符序列
   （会被转成真实换行导致 PowerShell 字符串未闭合）。可靠做法：
   PowerShell 行数组 + [IO.File]::WriteAllLines / AppendAllText（UTF8 no BOM），
   JS 代码里字符串一律用单引号（PS 内写两个单引号）、换行用 String.fromCharCode(10)，
   修复已有文件用 ReadAllText/WriteAllText + String.Replace。
8. **图片编辑器 accept 不含 gif**：canvas drawImage 只取第一帧，会造成「编辑了但导出不动」的困惑。
9. 文件名用 -Date.now() 取负数当临时 id（draft），正式 id 用自增 nextIdRef，避免冲突。

### 用户验证阶段修复（v2 交互细节）

10. **文本输入框创建后立即消失（blur 窃焦）**：点击图片 -> textarea 挂载并 autoFocus，
    但本次 click 事件在挂载后才派发，目标非可聚焦元素，浏览器把焦点移回 body，
    触发 onBlur -> 空文本提交被丢弃 -> 输入框闪现即消失。
    修复：创建/重编辑后置 ignoreTextBlurRef 忽略 blur，用户 pointerdown 到 textarea 才恢复；
    Escape 时同步清理标志。
11. **datalist 搭配 type=number 不可靠**（Chrome 按已输入内容过滤候选、Safari 不支持），
    预设档位下拉必须自绘菜单：relative 容器 + 绝对定位列表 + 容器 onBlur 判 relatedTarget 关闭。
12. **拖拽入栈要真实判断位移**：onDragEnd 若恒报 changed=true，「点选未拖动」也会污染撤销栈；
    pointerup 时用 JSON 对比当前与 orig 快照。
13. **useCallback 里引用声明在后的变量**会报 TS2448，改从 ref（如 annotationsRef）读取。
