# 2026-08-30

## 图像裁剪工具（src/app/tools/image/crop/page.tsx）迭代

标题改为「图像旋转、镜像、裁剪」，功能包含：
- 裁剪比例：原始宽高比 / 1:1 / 4:3 / 16:9 / 3:4 / 9:16 / 自定义（宽:高 数值输入）
  - `aspectMode` 类型由 `number | null` 改为 `number | "original" | "custom"`
  - 自定义非法输入（空/0/负数）时 `customAspect` 退化为 1，避免 Cropper 计算 NaN
- 缩放：`ZOOM_MIN=1`、`ZOOM_MAX=5`、`ZOOM_STEP=0.01`、`zoomSpeed=0.3`
- 旋转：滑块 + 数值输入框，`ROTATION_STEP=0.1`，通过 `normalizeRotation()` 归一化到 (-180,180] 并保留 0.1° 精度，支持 ±0.1°/±90°/归零
- 批量：拖入多张图，分辨率必须与第一张一致，不一致的拒绝并弹黄色提示；结果支持单个预览/下载 + JSZip 打包下载

## lib/image/crop.ts 越界防护

裁剪框可能超出旋转后画布（高倍缩放或极端自定义比例）。改为只绘制「裁剪框 ∩ 画布」部分并偏移到对应位置，越界区留白，避免 `drawImage` 源矩形越界导致拉伸变形。输出尺寸仍等于裁剪框尺寸。

## 参数化裁剪批处理（src/app/tools/image/parameter-crop/page.tsx）
